约 3 MB · 未签名，需要用任意自签工具装一次

先看清楚这一步：这个 App 本身也是一个 ipa，iOS 不允许未签名的 App 直接安装。 所以第一次要用你手头已有的自签工具（全能签、轻松签、AltStore、SideStore 都行）把它签一下装上。 装好之后，它就不再需要别的证书了。

怎么用

  1. 读出本机 UDID 打开 App 会自动尝试读取。读不到就点「去 Safari 获取 UDID」，装一次描述文件就能拿到，回来粘贴。
  2. 填 Apple ID 和密码 直接和 Apple 的服务器通信，密码不会经过任何第三方。
  3. 输一次验证码 双重认证的 6 位码会推到你信任的设备上，两分钟内有效。
  4. 导出 p12 和描述文件，导进全能签 两个文件都在「文件 App → 我的 iPhone → YZL签名器」里，p12 密码是 yzl123。
  5. 用全能签签启动器，再安装 这次签出来的包带 get-task-allow，StikDebug 里就能看到并开启 JIT。

常见问题

装好了，点图标没反应

去「设置 → 隐私与安全性」，拉到底打开「开发者模式」，重启后确认。这个开关只有在装过一次开发签名的 App 之后才会出现。

提示无法验证 App / 无法安装

两种原因。一是描述文件里没有这台设备的 UDID，检查第一步有没有读对；二是免费账号的证书过期了，重新签一次即可。

会不会用掉我的证书名额

会占一个，这是 Apple 的规则。但证书会缓存在本机，重签同一个包时直接复用，不会每次都申请新的。想换一张可以在 App 里点「忘记本机证书」。

7 天后怎么办

重新打开 App 签一次。账号信息会记住，证书如果还在有效期内就直接复用，比第一次快很多。

需要电脑吗

不需要。整个流程都在手机上完成，包括向 Apple 申请证书、注册设备、生成描述文件和签名。
